# LUNEX 统一拼装与评审设计

日期：2026-09-29

## 目标

把现有“素材浏览”“首页拼装”“幻灯评审”合并成一个“拼装”工作区。评审人应当能在完整网页画布里直接换图、点赞、插页和排序，并在结果页筛选多人点赞数据。

## 导航与页面结构

顶部只保留两个主入口：

1. **拼装**：承载素材浏览、网页拼装和逐图评审。
2. **评审结果**：查看、过滤和排序所有图片的云端票数。

拼装页是一列完整网页画布。首次使用时包含七个默认区块，顺序为首屏、产品与结构、使用场景、包装清单、版本选购、服务保障、页脚。

## 拼装画布

每个区块由一个稳定的实例标识、当前图片路径和原始分类组成。默认区块与用户插入的自选页使用同一种数据结构，因此都能参与排序。

鼠标移入或键盘聚焦区块时，在图片上方显示操作条：

- 拖动手柄；
- 上一张；
- 点赞与云端总票数；
- 下一张；
- 上移与下移；
- 在当前区块后插入自选页；
- 删除区块。

默认七区块与自选页都允许删除。删除图片实例只改变当前拼装，不删除磁盘素材或云端点赞。为避免误删后无法继续，画布至少保留一个区块；最后一个区块不显示删除操作。

拖动可改变区块顺序。每个区块也提供“上移”和“下移”操作，作为触控设备及无障碍操作的替代方式。排序完成后立即保存。

## 图片切换与素材抽屉

区块的“上一张”和“下一张”按照素材清单的固定顺序遍历全部 154 张图片，不限制为该区块的原始分类。到达最后一张后回到第一张，反向亦然。

每个区块显示当前素材的分类、版本、名称以及“第 N / 154 张”。同一张素材允许同时出现在多个区块。

左侧素材抽屉可按分类和版本筛选。用户先激活一个画布区块，再从抽屉选择素材；选择后直接替换该区块。点击“增加自选页”时打开同一抽屉，选择的现有素材作为新实例插到当前激活区块后；没有激活区块时插到画布末尾。

不支持上传电脑里的新图片。

## 随机拼装

点击“随机拼装”时：

- 每个默认区块只从其原始分类中随机选择一张图片；
- 用户插入的自选页不变；
- 区块顺序不变；
- 随机结果立即保存。

这种规则保持完整首页的基本语义，同时保护用户已经手工挑选的自选页。

## 评审行为

每次通过左右按钮查看图片，或通过素材抽屉选择图片，都把该图片记录为“已看”。同一图片重复出现只计算一次。页面顶部显示“已看 N / 154”。已看记录保存在当前浏览器本地，不跨设备同步。

点赞按钮直接显示云端总票数，并区分当前匿名用户是否已点赞。点赞沿用现有 Supabase 匿名身份、`image_likes` 表和实时订阅，不改变数据库结构或既有数据。

断网或 Supabase 不可用时，拼装、换图、插页、删除、排序和随机仍可使用；点赞按钮禁用并显示云端未连接提示。恢复连接后重新读取总票数和当前用户点赞状态。

## 评审结果

结果页使用同一份素材清单和实时点赞数据，提供可组合的筛选条件：

- 分类：全部或七个具体分类；
- 版本：全部或具体版本；
- 点赞状态：全部、有人点赞、我点赞的、零票；
- 排序：点赞最多、点赞最少、版本新到旧、版本旧到新。

结果头部显示筛选后的图片数量和最高票数。没有匹配项时显示明确空状态和“清除筛选”按钮。

点击结果卡片返回拼装页，并将所选图片放入最近激活的区块；若尚无激活区块，则使用画布第一个区块。这个操作也记录为已看。

## 本地状态与升级

新版使用版本化的本地状态，保存：

- 区块实例及顺序；
- 最近激活的区块；
- 已看图片集合；
- 结果页筛选条件。

首次载入新版时，如果发现旧版 `lunex-homepage-composer-v1` 选择数据，则将七个分类选择迁移为七个默认区块，并保留旧值。迁移完成后写入新版状态；旧键保留，便于回退。

本地状态损坏或引用不存在的素材时，忽略无效部分并使用对应分类的最新素材恢复默认区块，不阻止页面打开。

## 代码边界

现有单文件页面会拆成以下职责，避免继续把状态、数据逻辑和视图混在一起：

- `index.html`：页面骨架与样式；
- `app-data.js`：素材清单与分类元数据；
- `app-state.js`：拼装状态、迁移、排序、随机、筛选和本地存储；
- `app.js`：DOM 渲染、拖动交互、Supabase 连接和事件绑定；
- `supabase-config.js`：已有公开连接配置。

纯状态逻辑不访问 DOM 或网络，以便自动测试。

## 验收与测试

自动测试至少覆盖：

1. 左右切图可跨分类并首尾循环；
2. 随机只在默认区块的原始分类内选择，且不改自选页与顺序；
3. 自选页插入、重复素材、删除与至少保留一个区块；
4. 拖动排序及上移、下移后状态持久化；
5. 旧版七分类选择正确迁移到新版；
6. 损坏或失效本地状态能够恢复；
7. 分类、版本、点赞状态过滤和四种排序；
8. 已看进度去重。

浏览器验收覆盖桌面和窄屏：区块操作、拖动排序、随机、抽屉选图、点赞状态、结果筛选及从结果返回拼装。发布后检查 GitHub Pages 首页和代表性图片返回 200，并确认页面显示“云端评审已连接 · 实时同步”。

## 不在本次范围

- 上传新图片；
- 将拼装顺序跨用户或跨设备同步；
- 管理员账号、评论或文字批注；
- 修改 Supabase 表结构；
- 导出拼装结果为图片或 PDF。
